## 已修 1：`serve_client.py` 的 PLACEHOLDER_PNG 损坏（bug 7 #2015）
`base64` 里 IDAT 长度声明 11、真实 13 字节 → CRC 不匹配、`zlib.decompress` 报
`incomplete or truncated stream` → Flash `ArgumentError: Error #2015` 于
`BitmapData/copyPixels()` ← `asgui.blit.data::BlitData/SetContent()`。
**所有缺失图片都返回它**，所以一处坏字节 = 任意面板崩溃，且栈里完全看不出是图片问题。
已换成自己生成的全透明 1x1（filter 0 + RGBA(0,0,0,0)）。
守护测试 `tests/test_placeholder_png.py`（7 项）：重解析签名/块长/每个 CRC32/zlib 解压/alpha。

## 已修 2：`_fields` 不认 repeated 字段（bug 8 的深层根因）
`_MSG_FIELD_RE` 的负向前瞻 `(?<!Repeated)` 是**故意**的（repeated 不能预填，否则撞
`RangeError #2006`），但副作用是"唯一字段是 repeated"的 SC 兜底产出 **0 字节**。
`Cmd_TD_GetChallengeLevelInfo_SC{infos}` 正是这种 → 客户端 `infos[]` 空 →
`getChallengeLevelInfo()` 返回 null → `updateInheritInfo` 读 `isCanInherit` → #1009。
修法：新增 `_REP_MSG_FIELD_RE`，`populate_message` 给每个 repeated 消息字段发**恰好一个**空元素
（既满足"至少一条"，又不会超过控件格子数）。`_fields` 返回值从 2 元组变 3 元组（**只有
`populate_message` 一个调用点**，已确认）。

## 已修 3：新增 `handle_td_getchallengelevelinfo`（bug 8）
CS 无字段；数据源 `levelselectInfo.txt` 里 19 行 `challengeLevelId != 0`。
新增 `load_td_challenge_levels()`（lru 风格缓存）+ `_TD_CHALLENGE_FREE_TIMES = 3`。
**每个 DTO 七个字段全写满**（都是 TYPE_UINT32，缺一个就读成 0）。
注册到 `REQUEST_HANDLERS`：`"PVZ.Cmd.Cmd_TD_GetChallengeLevelInfo_CS"`。

## 已修 4：超级配药的两轴语义混用（bug 1）
反汇编确认结果面板 4 个实参（`ModuleNutrition.swf`）：
```
openTradeResult(sc.cost, sc.newExp - sc.oldExp, sc.qualityNum, sc.goldReagentNum - before)
```
且 `txtCost` 的编译期标签就是「消耗金币：」，`getCostType()` 只产出 1/2/3。
→ **cost 只能是 200000/500000/1000000**，截图里的 `310000` 不可能来自 cost，
   说明那张截图是**旧代码**的产物（`310000/10000=31` 杯，`31//10=3` 黄金原液、
   `31×45%≈14` 溶解 ×100 药粉 = 1400、`31×55%≈17` 保留 —— 四个数完全自洽）。

真 bug 是 `_nutrition_roll(change_type)`：把**分解档位**当**营养师档位**传。
橙档(5)恰好 alias 营养师 5 所以看着正常，但绿蓝档(3) alias 营养师 3，
让**最便宜的分解设置产出最差的试剂**。而且各营养师的品质跨度太窄（5/6 只出 q5/q6），
导致 changeType 3 和 4 产出**完全相同** → "选绿蓝和选紫没区别"。
改为独立的 `_NUTRITION_SUPER_TRADE_TIERS`（三档都覆盖 q3..q6）+ `_nutrition_supertrade_roll(cost_type)`。
九宫格实测：同 costType 下 changeType 越高保留越少药粉越多；同 changeType 下 costType 越高越好。
金币不足时**整笔拒绝**而非部分酿造（部分酿造仍扣全额，正是"金币扣除有问题"）。
测试 `tests/test_nutrition_supertrade_axes.py`（8 项）。
